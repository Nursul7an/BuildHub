Главная проверка
Показать панель человеку, не видевшему приложение: каждая иконка должна угадываться без подписи. Кран = объекты, каска = подрядчики, штамп = приёмка, коробка = заявки, колокольчик = уведомления. Бейджи: красный с числом — требует действия; серая точка — просто новое. «Ещё» агрегирует бейджи содержимого.
